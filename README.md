# ♡ Mi Rincón Artístico 🎨

¡Bienvenidos a mi pequeño mundo creativo!

Este es mi primer proyecto personal de desarrollo web. Lo estoy creando para aprender programación y compartir mi pasión por el dibujo.

## 🌷 Características

- Diseño con colores rosa pastel y lila.
- Galería para mostrar mis dibujos.
- Botones interactivos con JavaScript.
- Decoraciones inspiradas en corazones y estrellas.

## 💻 Tecnologías utilizadas

- HTML: estructura de la página.
- CSS: diseño y estilos.
- JavaScript: interactividad.

## ✨ Objetivo

Seguir aprendiendo desarrollo web, experimentar con nuevas ideas y mejorar este proyecto poco a poco.

*Hecho con creatividad y mucho cariño ♡*
